# Third-party data: Samsung CredData

Most repositories in `bench/dev/` are built from
[Samsung CredData](https://github.com/Samsung/CredData) ("Project CredData: A Dataset of Credentials
for Research", JaeKu Yun, ShinHyung Choi, YuJeong Lee, Oleksandra Sokol, WooChul Shim, Arkadiy Melkonyan,
Dmytro Kuzmenko, 2021).

- **CredData's own code and metadata** are licensed under the
  [Apache License 2.0](https://github.com/Samsung/CredData/blob/main/LICENSE) (copy in `bench/licenses/CredData.LICENSE`).
- **The source files** are open-source code from public GitHub projects. As CredData states, *"each file
  is under the existing project's license"*. These licenses differ from project to project: there are
  permissive ones and copyleft ones such as the GPL. The `<RepoID>` directory names are CredData's own
  repository IDs. For each repository, the license files of the original project are in
  `bench/licenses/<RepoID>/`. Three repositories (`262e8107`, `7f8b28a7`, `f129be24`) came from CredData
  without a license file.
- The files are not identical to the originals. CredData already obfuscated their paths and credential values,
  replacing real secrets with fake ones. For this challenge we then **changed them** further:
  we inserted fake secrets and decoys, renamed and mutated lines, and cropped large files. Nothing in
  `bench/dev/` is a real, working credential.
- Files that do not come from CredData were generated by us. They are covered by `LICENSE`, as are
  the labels (`*.labels.json`) and everything outside `bench/`.

The data is provided for this hackathon, for research and for testing secret detectors. When you
reuse or redistribute files from `bench/dev/`, keep `bench/licenses/` with them and follow the
license of the original project. If you publish results based on the data, please cite CredData
([BibTeX in their README](https://github.com/Samsung/CredData#citation)).
